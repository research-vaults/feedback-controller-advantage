# Replay of the main-paper headline comparison

Run `python3 reproduce.py` from any directory after installing NumPy. Inputs are 720 saved terminal hit-count records in `outcomes.csv`: six models × six readouts × twenty matched starts. There are no gene identities, feature matrices, API credentials or model calls. Each row pairs outcomes for policies sharing the same initial batch; later histories differ.

The script checks row/cell identities and recomputes assignment benefit (TRUE minus permuted), availability benefit (TRUE minus withheld) and controller advantage (LLM TRUE minus uniform-hit TRUE). It uses equal model/readout weights, 20,000 paired within-cell bootstrap draws, seed 80908 and 98.333333% percentile intervals (three Bonferroni contrasts, nominal 95% family coverage). Biological sources are fixed, not resampled populations. The family was specified before this replay but after the original outcomes were available: this is retrospective reporting, not new confirmation. The manuscript's original four primary contrasts remain unchanged.

`EXPECTED_RESULTS.json` is the retained result; `SHA256SUMS` identifies the package. The script verifies its computed values to absolute tolerance 1e-10. `PROVENANCE.json` records the upstream saved-block checksum and extraction rule. This subset permits numerical audit from saved outcomes; it cannot regenerate model proposals, biological outcomes, intermediate histories or verify correctness of the upstream experiments independently. The full upstream project is not made public by inclusion of this subset in the manuscript source archive. Python and NumPy version information is recorded in the results receipt in the project.
