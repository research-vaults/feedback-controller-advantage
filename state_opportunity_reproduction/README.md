# Observed-state opportunity: exploratory prediction

Run `python3 reproduce.py` with Python 3 and NumPy. It recomputes all 720 source-excluded predictions for six fixed specifications, source/macro errors, selection gains and conditional paired bootstrap intervals from `STATE_FEATURES.csv`. It checks saved RESULTS/PREDICTIONS without modifying files or making network/API calls. Three primary specifications are a constant, hit-count ridge and four-feature ridge. Matched deployment-indicator versions are sensitivities. Regularization is 10, seed 260927, with 20,000 bootstrap draws; no tuning uses held-out outcomes.

Features concern acquired state only: observed-hit count, hit-neighbour union coverage, overlap and acquired-neighbour depletion. Lists of 26 neighbours match the maximum centre quota. Full geometric regeneration requires the frozen Achilles matrix and original acquired-gene records, which are not redistributed here. The local source audit checked 1,440 paired batches, 720 future-outcome mutation cases and direct rank recomputation on all six readouts. The 720 computational starts include 667 distinct initial gene sets within model/readout groups; they are not biological replicates. Correlated readouts remain grouped.

The continuation gate failed: only one of four sources had lower squared error than hit count, and selection gained 0.0583 hits/128 against a pre-analysis planning threshold of 0.5. No paid campaign or modern-cohort stress test followed. This tests state features rather than the earlier proposal features; it is not the first source-excluded predictor or independent biological confirmation. All sources are development evidence. Intervals condition on fitted folds and omit training-fit/new-source uncertainty. Definitions, limits and source results appear in Appendix E.2.
